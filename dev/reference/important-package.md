# important: Supervised Feature Selection

Interfaces for choosing important predictors in supervised regression,
classification, and censored regression models. Permuted importance
scores (Biecek and Burzykowski (2021)
[doi:10.1201/9780429027192](https://doi.org/10.1201/9780429027192) ) can
be computed for 'tidymodels' model fits.
